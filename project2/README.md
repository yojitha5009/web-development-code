# NovaBook Pro - Responsive Product Landing Page

## 📌 Project Overview

NovaBook Pro is a responsive laptop product landing page created as part of the Week 02 Minor Project.

The purpose of this project is to demonstrate the use of modern CSS concepts, responsive web design, Flexbox, CSS Grid and Tailwind CSS.

The webpage presents a fictional laptop product called "NovaBook Pro".

---

## 🎯 Project Objectives

The main objectives of this project are:

- Create a professional product landing page.
- Use HTML5 for the webpage structure.
- Use CSS3 for styling.
- Implement layouts using Flexbox.
- Implement layouts using CSS Grid.
- Create a responsive design.
- Use Tailwind CSS.
- Create a mobile-friendly webpage.
- Add product features and benefits.
- Add customer testimonials.
- Add a pricing and call-to-action section.
- Publish the project using GitHub.
